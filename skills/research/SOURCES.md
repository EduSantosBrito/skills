# Sources and provenance

This skill is a rewritten adaptation of two MIT-licensed sources:

- Matt Pocock's [`research`](https://github.com/mattpocock/skills/blob/5b15a47f2d7150f545fbcacbfe381787fc0230dc/skills/engineering/research/SKILL.md), revision `5b15a47f2d7150f545fbcacbfe381787fc0230dc`. It contributed the primary-source posture, background delegation, and single durable research artifact. See `LICENSE-mattpocock`.
- Lauren Tan's pstack [`why`](https://github.com/cursor/plugins/blob/46125561306434d8a1d7745d540d8932ab0cd2a2/pstack/skills/why/SKILL.md), revision `46125561306434d8a1d7745d540d8932ab0cd2a2`. It contributed broad rationale ownership, code/history anchoring, bounded null results, explicit epistemic classes, contradiction handling, and verifiable citations. See `LICENSE-pstack`.

The local design intentionally selects sources according to the question rather than copying pstack's fixed evidence-category sweep. It also removes pstack-specific model names, Cursor task schemas, and assumptions about available MCPs. Background work follows the repository's Wayfinder ownership and handoff contract.

No upstream source file is copied verbatim beyond short names and conventional labels. The bundled licenses preserve the upstream notices for this adaptation.
